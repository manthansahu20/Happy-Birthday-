# 🎉 Happy Birthday Website

A beautiful and interactive **Happy Birthday** website built with **HTML, CSS, and JavaScript** to make someone's special day even more memorable. This project combines smooth animations, engaging effects, and a personalized birthday message into a delightful web experience.

## 🌐 Live Demo

👉 **Live Website:** https://manthansahu20.github.io/Happy-Birthday-/

---

## ✨ Features

* 🎂 Beautiful birthday greeting page
* 🎈 Smooth animations and transitions
* 🎵 Background music for a festive experience
* 💖 Personalized birthday wishes
* 📱 Fully responsive design
* ⚡ Lightweight and fast
* 🌈 Attractive UI with modern styling

---

## 🛠️ Built With

* **HTML5**
* **CSS3**
* **JavaScript**

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/ManthanSahu20/Happy-Birthday-.git
```

### Navigate to the Project

```bash
cd Happy-Birthday-
```

### Run the Project

Simply open **index.html** in your browser or use **Live Server** in VS Code.
